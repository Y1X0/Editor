# ai_pipeline — مسار توليد فيديو عربي سينمائي

نص عربي + صوت → MP4 عمودي 1080×1920. **الذكاء الاصطناعي بيقرّر WHAT،
والكود بينفّذ HOW.**

نظام أخو `autoreel/` بنفس المستودع، **معزول عنه**. للحدّ بينهن شوف
`CLAUDE.md` بالجذر — الخلاصة: `ai_pipeline ──► shared ──► autoreel`،
اتجاه واحد، وعليه حرّاس.

```bash
python -m ai_pipeline.cli plan    projects/<id>   # بيستدعي LLM، بيكتب عقودًا
python -m ai_pipeline.cli fetch   projects/<id>   # شبكة
python -m ai_pipeline.cli render  projects/<id>   # حتمي — ولا نداء LLM
```

## ⚠️ `final.mp4` صيغة تسليم، مش تمثيلًا داخليًا

```
ai_pipeline
    ↓
تمثيل المشروع  (Timeline · Assets · Typography · Audio)
    ├──► لاحقًا: مشروع/timeline أصلي بالمحرر
    └──► اليوم:  FFmpeg → final.mp4
```

**قرار مثبَّت:** التمثيل الكامل للمشروع بيضل بالعقود. `final.mp4` فرع
من التمثيل، **مش التمثيل**. أي شي بينحسب وقت الرندر وما بينحفظ بعقد
بيقفل باب التكامل الأصلي مع المحرر لاحقًا — وقتها التكامل بيصير إعادة
كتابة بدل إضافة مُصدِّر.

عمليًا: `timeline.json` لازم يكفّي لإعادة بناء المشروع كاملًا بلا ما
تقرا كودًا. لو احتجت تشغّل الرندر عشان تعرف وين مقطع، فالعقد ناقص.

## ⚠️ اقرأ هذا قبل أي تعديل على النص العربي

**لا تستخدم `arabic_reshaper` ولا `python-bidi`.** Pillow المبني مع
**libraqm** بيعمل shaping + bidi لحاله.

**وهاد مقيس، مش مأثورًا** (`docs/ai-video-pipeline/SPIKE-FINDINGS.md` / F1):

```
arabic_reshaper.ArabicReshaper().configuration["delete_harakat"]  ->  True
"وَمَن يَتَوَكَّلْ عَلَى اللَّهِ فَهُوَ حَسْبُهُ"  (47 محرف · 20 حركة)
        →  "ﻭﻣﻦ ﻳﺘﻮﻛﻞ ﻋﻠﻰ ﷲ ﻓﻬﻮ ﺣﺴﺒﻪ"     (24 محرف ·  0 حركة)
```

والرسم بعدها بيطلع **مقلوبًا وحروفه مفكوكة**. حذف ٢٠ حركة من آية هو
كسر §19 بالإعداد الافتراضي — مش بسوء استعمال.

الصح:
```python
from PIL import features; assert features.check("raqm")
draw.text(xy, raw_arabic_text, font=f, direction="rtl", language="ar")
```

## ⚠️ النص المصدر غير قابل للتغيير

الوكيل **ما بيكتب نصًا**. بيكتب `word_start`/`word_end`، والكود بيجيب
الشريحة من المصدر. `text_arabic` بالعقد **صدى للقراءة البشرية**
بينتقارن بايت-بايت، وأي اختلاف بيرمي `TextIntegrityError`.

وفي حارسان مش واحد: `check_text_integrity` (ولا حرف بيتغيّر) و
`check_coverage` (ولا كلمة بتنحذف بالسكوت).

---

## ⚠️ الوكيل ما بيكتب توقيتًا

`segments.json` **ما فيه `start` ولا `end` ولا `duration`** — بالقصد.
الوكيل بيقرّر **وين يقسم** (WHAT)، والكود بيحسب **إيمتى** (HOW) من
`alignment.json`.

النتيجة إن ست حالات فشل بتصير **مستحيلة بالبناء** بدل ما تنكون مفحوصة:

> `start >= end` · توقيت سالب · تداخل مقاطع · `duration` مش مطابقة ·
> ترتيب معرّفات غلط · توقيت خارج مدى الصوت

وعليها فحص بيقرا الـschema: `test_segments_contract_has_no_time_fields`.

**القاعدة الأعمّ: العقد يحمل القرارات فقط، لا المشتقّات.** كل حقل
مشتقّ بتخزّنه بيولّد قاعدة تحقّق لتمسك تناقضه.

---

## ⚠️ الفهرس هو الزمن

ffmpeg بيرمّز **إطارات**، مش ثواني. `timeline.json` هو **الحدّ الوحيد**
بين العالمين، و`quantize()` هي المكان الوحيد اللي بيعبره.

- `sample = frame × (sr // fps)` — ضرب صحيح. `Output` **بترفض** أي fps
  ما بيقسم الـsample_rate (29.97 ممنوعة: 1601.6 عيّنة/إطار).
- `total_samples = total_frames × samples_per_frame` — بينثبّت بالبناء
  (`apad,atrim=end_sample=N`)، ما بينفحص بعدين.
- **نوعان من الـspans** (F7): `visual` بتغطّي `[0, total_frames)` كاملة،
  و`text` بتترك فجوات مقصودة. الكلام بيبلّش بعد الإطار صفر.

## ⚠️ طبّع قبل ما تفهرس

| الحقيقة | التطبيع | ليش |
|---|---|---|
| معدل الإطارات | `fps={fps}` **قبل** `trim` | الأصل 25fps والمخرَج 30 |
| معدل العيّنات | `aresample={sr}` قبل `atrim` | فهرس العيّنة مشتقّ من الإطار |
| **نسبة البكسل** | **`setsar=1` بعد `crop`** | ← اقرا تحت |

**حادثة SAR (F5):** المخرَج طلع بوسمين متناقضين — الحاوية `SAR 1:1`
والترميز `SAR 10240:10239`. السبب:

```
3840/2160 × 1920 = 3413.333…  →  ffmpeg بيقرّب لـ3413
10240/10239   = 1.0000976657876746
3413.333/3413 = 1.0000976657876746   ← نفس الرقم بالضبط
```

`scale=…:force_original_aspect_ratio=increase` بيعطي هدفًا غير صحيح،
فffmpeg **بيعوّض بـSAR** بدل ما يشتكي. ولا تحذير، وexit code صفر.

## ⚠️ التشكيل بيتجاوز الـfont metrics

عند `size=72` مع علامات الوقف القرآنية:

| الخط | ascent | أعلى حبر فعلي | التجاوز |
|---|---|---|---|
| `Amiri-Bold` | 81 | 127 | **+46px = ٦٤٪ من حجم الخط** |
| `AmiriQuran-Regular` | 131 | 128 | −3 ✅ |

**ارتفاع السطر من صندوق الحبر الفعلي، لا من `getmetrics()`.**
و`AmiriQuran-Regular` افتراضيًا للنص القرآني.

## ⚠️ النص بيختفي على لقطة فاتحة

نسبة التباين (WCAG) على لقطة فاتحة طلعت **1.06** — النص غير مرئي
عمليًا. مع scrim بشفافية 165 صارت **5.64**.

حارس تباين **مقيس** على الإطار اللي ffmpeg بيسلّمه (بعد scale+crop)،
مش على الأصل. والـscrim بينرسم **جوّا صورة الكابشن** — بلا فلتر ffmpeg
إضافي وبلا overlay تاني.

## العقود بتنقرا من JSON بالوضع الصارم

```python
SegmentsContract.model_validate_json(text)     # ✅ مصفوفة JSON -> tuple
```

`strict=True` + `extra="forbid"` + `frozen=True`:

- `"1"` مكان `1` **بينرفض** — الـLLM بيرجّع نصوصًا مكان أرقام، والقبول
  الصامت بيمرّر قرارًا مخترَعًا.
- مفتاح زيادة **بيفشل**، ما بينتجاهل.
- العقد بعد القراءة ما بيتغيّر — أي اشتقاق بيطلّع قيمة جديدة.

بالبايثون المباشر مرّر `tuple` مش `list` (نتيجة الوضع الصارم).

### قاعدة: افحص الحارس بحالة سيّئة معروفة

**الطقم الأخضر ما بيثبت شي لحاله.** بعد ما تكتب مدقّقًا، **اكسره
عمدًا** وشوف إذا الطقم بيمسكه.

الحادثة: بعد ما خلصت 50 فحصًا خضرا، شلت **قصّ التداخل** من
`quantize()` — و**مرقت الطفرة بلا ولا فشل**. السبب إن الـfixture ما
فيها كلمات متداخلة أصلًا، فالمسار ما كان مغطًّى. الفحص الأخضر كان
بيغطّي غياب التغطية.

### قاعدة: نتيجة الاختبارات بتنذكر مع نسخة ffmpeg

«٥٢ ناجحة» ادعاء ناقص. «٥٢ ناجحة على ffmpeg 7.0.2» ادعاء.

### قاعدة: قِس خط الأساس قبل التعديل

بلا خط أساس ما بتقدر تنسب الفشل — ولا تعرف إذا الفاشلة منك ولا كانت
هناك من قبلك.
