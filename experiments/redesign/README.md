# تجارب `REDESIGN-SPEC.md`

**مش كود إنتاج، ومش جزء من `pytest`.** هدول السكربتات اللي انقاس فيها كل
رقم بـ`REDESIGN-SPEC.md`. محفوظين هون لسبب واحد: **مواصفة بأرقام
غير قابلة لإعادة الإنتاج = مواصفة بلا أرقام.**

انكتبوا وانشغّلوا بـ`/tmp/realrun/` على **ffmpeg 7.0.2-static**. المسارات جواتهن
مطلقة (`/tmp/realrun/...`) — لو بدك تعيد التشغيل، اعمل المجلد وشغّل
`mkclick.py` أول شي.

```bash
mkdir -p /tmp/realrun && cp experiments/redesign/*.py /tmp/realrun/
cd /tmp/realrun && python mkclick.py       # المصدر: نقرات بأزمنة معروفة
python det.py                              # تحقّق من الكاشف (أرضية ٢ms)
python e16.py 30 120                       # التكامل: الثوابت الثلاثة
python z0.py                               # تحقّق من قارئ الزوم
python z2.py                               # يبني مصدر الباركود ويتحقّق منه
python z7.py 30 150                        # الزوم + الكابشن + الصوت سوا
```

| السكربت | السؤال |
|---|---|
| `mkclick.py` | يبني `click.mp4`: نقرة كل ٠.٥s بأزمنة معروفة بالضبط |
| `det.py` | كاشف قمم النقرات + **اختبار أرضيته على المصدر نفسه** |
| `e2.py` | الخلل بالـtrim ولا بالـconcat ولا بالمرمِّز؟ |
| `e3.py` | أي صياغة بتعطي عدد إطارات المخطط بالضبط؟ |
| `e4.py` | وين بينضيع معدّل الإطارات؟ (الجواب: `setpts`) |
| `e6.py` | انزياح الصوت: المعمارية الحالية مقابل المقترحة |
| `e8.py` | ٤ مخرجات برسم واحد (انتهت بـOOM ١٣.٥ GiB) |
| `e9.py` | ٣ صياغات كابشن أرخص |
| `e10.py` | `select` بدل `split`+`trim` |
| `e11.py` | demux مقابل chain مع تصحيح معدّل الإطارات |
| `e12.py` | الهجين: `select` للفيديو + `atrim` للصوت |
| `e13.py` | التوسّع: الذاكرة مقابل عدد المقاطع والمخرجات |
| `e14.py` | هل كل كابشن بيبلّش على إطاره؟ (كشف قاعدة زمن ١/٢٥) |
| `e15.py` | تسلسل صور مفهرس بالإطار |
| `e16.py` | التكامل: الثوابت الثلاثة بنفس التشغيلة |
| `e18.py` | المقارنة النهائية بإعدادات ترميز عادية |
| `z0.py` | أداة قياس معامل الزوم + **اختبار أرضيتها** (٠.٠٠٠٧) |
| `z1.py` | خيار أ١ مقابل الخط الأساسي |
| `z2.py` | مصدر كل إطار فيه بيحمل رقمه (باركود) + اختبار قارئه |
| `z3.py` | فحص **كل إطار**: هويته وزومه وحدوده |
| `z4.py` | أي فلتر بالجذع بيسقّط الإطار؟ |
| `z5.py` | `settb`+`setpts=N` مقابل `setpts=N/FPS/TB` |
| `z6.py` | مصفوفة التوسّع: ٣ أحجام قص × ٣ أعداد مخرجات |
| `z7.py` | تكامل الزوم مع الكابشن والصوت — خمس ثوابت |
| `z8.py` | المقارنة النهائية والزوم شغّال بالطرفين |

`e1.py` (الرسم المفترَض اللي طلع ١٨٦/٢٢٣) و`e5.py` (الكاشف اللي ما لقى
نبضات) و`e7`/`e17` (فقرات قصيرة انشغّلت من السطر) مش هون — نتيجتهن
مسجَّلة بـ§12 من المواصفة.
