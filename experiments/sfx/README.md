# قياسات تصميم الصوت (SFX)

سكربتات القياس لـ`SFX-SPEC.md`. **ولا واحد منهن بيلمس كود الإنتاج** —
كلهن بيبنوا مصادرهن وبيشغّلوا ffmpeg مباشرة.

| السكربت | بيقيس | النتيجة المختصرة |
|---|---|---|
| `tools.py` | أدوات: فكّ PCM، كاشف نبضات بعتبة **نسبية**، توليد نقرة/صمت | أرضية الكاشف ٢ عيّنة |
| `s1_adelay.py` | دقة `adelay` بالعيّنة مقابل الميلي | `S` صفر خطأ · ميلي صحيح ±٢٣ عيّنة |
| `s2_amix.py` | مستوى `amix` وتنفّس الكسب | `normalize=1` -> ٠.١١× عند ٢٠ مؤثرًا + ضخّ |
| `s3_preserve.py` | حفظ الكلام عيّنة بعيّنة | `normalize=0` -> **٠ عيّنة متغيّرة** |
| `s4_clip_format.py` | القصّ ومطابقة الصيغة | فخّان صامتان: القنوات ومعدّل العيّنة |
| `s5_scale.py` | ذاكرة/وقت/حجم رسم مقابل N | خطّي · ٩٤M عند ٢٠٠ · ٢١٧M عند ٥٠٠ |
| `s6_reuse.py` | مدخل لكل مؤثر مقابل `asplit` | `asplit` بتوفّر ٣٤–٣٨٪ |
| `s7_integration.py` | دمج فعلي بالمسار الحقيقي | E1 وE2 صامدين · ٨/٨ مؤثرات ≤٢ عيّنة |
| `s8_headroom.py` | الهامش و`alimiter` | `alimiter` بيأخّر ٢٣٩ عيّنة |

**تنبيه على أداة القياس:** الكاشف عتبته نسبية لقمة الإشارة، فبيلزمه
**سرير صامت**. تشغيله على سرير فيه كلام عالي بيخلّيه يمسك الكلام
نفسه ويرجّع مواقع بلا معنى — صار معنا فعلًا (−٢٣٩٨٤ عيّنة).
