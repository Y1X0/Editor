# سرير موسيقي محايد

**تجريبي، مش خيارًا فنّيًا.** موجود عشان تشوف أثر الموسيقى على الإيقاع
والمزج بلا ما تنتظر مقطعًا مرخَّصًا. لريل حقيقي حطّ موسيقاك:

```bash
python -m autoreel.cli in.mp4 --music track.mp3 -o out.mp4
```

## المصدر

`build_music.py` — **تركيب رياضي بلا أي مصدر خارجي**، نفس منطق
`assets/sfx/`. عمل أصلي للمشروع، ترخيصه ترخيص المستودع، وما في طرف
تالت أصلًا. قابل لإعادة الإنتاج بالبايت:

```bash
python assets/music/build_music.py
```

## المواصفات

| | |
|---|---|
| الشكل | WAV · 48000Hz · ستيريو · PCM s16le |
| المدة | ٨.٠٠s (٣٨٤٠٠٠ إطار) |
| الذروة | ٠.٩٠ لكل قناة · ٠.٥٢ بالمزج الأحادي |
| RMS | ‎−١٧.٤ dB |
| النوتات | A2 · C3 · E3 · A3 (لا مينور) |
| النبض | ١٢٠ نبضة/دقيقة |

## اللفّة بلا نقرة — بالبناء مش بالتلاشي

بتنلفّ بـ`-stream_loop -1`، فآخر عيّنة بتلحقها أول عيّنة مباشرةً. أي
تردّد ما بيكمّل **دورات صحيحة** بطول المقطع بيخلق قفزة مسموعة كل لفّة.

الحل: كل تردّد بينتقرّب لأقرب مضاعف صحيح لـ`1/المدة` (شبكة ٠.١٢٥Hz
عند ٨ ثواني — أدقّ بكتير من تمييز الأذن). نفس المبدأ على مغلّف النبض.

مقاس على الملف الفعلي:

```
قفزة التماس بين لفّتين  = 7.32e-04
أكبر قفزة داخل المقطع   = 1.59e-02      ← أكبر بعشرين ضعفًا
```

والسكربت بيفشل لو انعكست النسبة.

## مقاس بالمزج

على لقطة حقيقية (٧١.٦s) مع `music.gain = 0.12`:

```
الكلام لحاله        −18.91 dB
المخرَج مع الموسيقى  −20.21 dB   ذروة 0.826 — ولا قصّ
الموسيقى معزولة     −35.53 dB   ← أقل من الكلام بـ15.2 dB
التلاشي            −38.5 عند ٠s ← −34.9 عند ١s ← −41.9 عند ٧١s
```

العزل بطرح `المخرَج − 0.85 × الكلام` — مش بالسماع.
